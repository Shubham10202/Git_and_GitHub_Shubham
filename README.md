# Git & GitHub Practical Assignment

This repository contains my practical work for learning and implementing Git and GitHub concepts.

## Project

A simple Flask To-Do application was created and used to practice Git and GitHub workflows.

## Tasks Completed

### 1. Repository Setup
- Created Git repository and connected it with GitHub.
- Configured `main` branch.
- Created and pushed feature branches.
- Practiced `git clone`, `git add`, `git commit`, `git push` and `git pull`.

### 2. API Development
- Created a Flask application.
- Added `/api` endpoint.
- Updated `data.json` with API response data.
- Committed and pushed changes using a separate branch.
- Merged the branch into `main`.

### 3. Branching, Merging & Conflict Resolution
- Created `master_1` and `master_2` branches.
- Added the To-Do frontend in `master_1`.
- Added `/submittodoitem` POST API in `master_2`.
- Integrated MongoDB using PyMongo.
- Merged both branches into `main`.
- Practiced merge conflict resolution.

### 4. Git Rebase
- Added the following fields to the To-Do form through separate commits:
  - Item ID
  - Item UUID
  - Item Hash
- Practiced `git reset --soft`.
- Rebased `master_1` onto `main`.
- Resolved rebase conflicts.
- Used `git push --force-with-lease` after rebasing.
